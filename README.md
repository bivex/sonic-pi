# sonic-pi

Music creation with Sonic Pi. A collection of compositions, sound design experiments, and live coding performances.

## Compositions

| File | Style |
|------|-------|
| `LYRICAL SHAKUHACHI — Hirajoshi Flute.rb` | Japanese traditional |
| `QUIET HOUSE – CINEMATIC GAME THEME (8 INSTRUMENTS).rb` | Cinematic / Game |
| `Cinematic Japanese Loss Theme — "The Mountain Remembers".rb` | Cinematic Japanese |
| `Mountain Omen.rb` | Ambient / Cinematic |
| `"Biwa no Yoru" — Ancient Heian Ritual Music.rb` | Ancient Japanese ritual |
| `Witch house halloween.rb` | Witch House |
| `Mountain Omen Crimson Eclipse.rb` | Dark ambient |

## Sound Design

- `mastering/good.rb` - Mastering reference
- `promts/sounddesing.md` - Sound design prompts and notes
- `witch_house.pi` / `demonic.pi` - Genre-specific experiments

## Getting Started

1. Install [Sonic Pi](https://sonic-pi.net/)
2. Open any `.rb` file in Sonic Pi
3. Press play to hear the composition
